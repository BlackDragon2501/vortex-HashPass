# Vórtex HashPass

Vórtex HashPass, de Vortex Company: genera contraseñas fuertes y frases de paso, evalúa su fortaleza y calcula hashes MD5, SHA-1, SHA-256 y SHA-512 de textos y archivos con Web Crypto. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
